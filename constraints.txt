# Pinned versions of the direct dependencies, at the versions the test suite
# currently passes against.
#
# Usage:
#   python -m pip install -e ".[dev]" -c constraints.txt
#
# What this file is and is not
# ----------------------------
# It pins *direct* dependencies, which is what this project controls. It is not a
# full transitive lock: a complete one should be generated with `uv lock` or
# `pip-compile`, and the first attempt to produce it here failed honestly --
# `pip freeze` on the development machine emits conda-local artifacts
# (annotated-types, anyio, h11, pydantic and others as `@ file://...`), which are
# not installable anywhere else. Committing that would have looked like a lock file
# and behaved like a broken one.
#
# The versions declared in pyproject.toml carry upper bounds, so an install without
# this file is still bounded rather than open-ended; this file narrows them to
# exactly what has been verified. Regenerate after upgrading deliberately.
#
